# Python Lists

This folder contains my Python list practice and exercises.

## Topics Covered

- Creating lists
- Accessing elements using indexing
- Negative indexing
- Updating list elements
- Adding elements using `append()`
- Iterating through lists using `for` loops
- Calculating totals using accumulators
- Calculating averages using `len()`

## Practice Programs

### list_practice.py
A student marks management program that:
- Stores student marks in a list.
- Adds a new mark.
- Updates an existing mark.
- Displays all marks.
- Calculates total and average marks.

## Learning Goal

Build a strong understanding of Python lists before moving to dictionaries and data-driven projects.
